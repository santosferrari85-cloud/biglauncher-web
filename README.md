# BigLauncher

BigLauncher is a free Steam launcher with a Big Picture-style interface, built from
the ground up to be played with a controller from the couch.

- **Website:** [santosferrari85-cloud.github.io/biglauncher-web](https://santosferrari85-cloud.github.io/biglauncher-web/) (published with GitHub Pages)
- **Downloads:** see this repository's [Releases](https://github.com/santosferrari85-cloud/biglauncher-web/releases)

This repository only contains the promotional website and the downloadable app
builds — it does not include the source code.

## Features

- Full controller navigation or keyboard/mouse
- Recent games, Library, Yearly stats, Store, Friends and Steam Community
- Memories Mode: revisits your play history after a while of inactivity
- Optional AI analysis (disabled by default)
- Ambient music per game, with a dedicated player
- Spanish, English, French and German

## Requirements

- Windows 10 or 11 (64-bit), or Linux (64-bit)
- Steam client installed
