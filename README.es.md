# BigLauncher

BigLauncher es un launcher gratuito para Steam con interfaz tipo Big Picture, pensado
de principio a fin para jugarse con mando desde el sofá.

- **Sitio web:** [santosferrari85-cloud.github.io/biglauncher-web](https://santosferrari85-cloud.github.io/biglauncher-web/) (se publica con GitHub Pages)
- **Descargas:** ver [Releases](https://github.com/santosferrari85-cloud/biglauncher-web/releases) de este repositorio

Este repositorio solo contiene la web promocional y las versiones descargables de la
app — no incluye el código fuente.

## Características

- Navegación completa con mando o teclado/ratón
- Recientes, Biblioteca, Estadísticas anuales, Tienda, Amigos y Comunidad de Steam
- Modo Memorias: repasa tu historial jugado tras un rato de inactividad
- Análisis con IA opcional (desactivado por defecto)
- Música ambiental por juego, con reproductor dedicado
- Español, inglés, francés y alemán

## Requisitos

- Windows 10 u 11 (64 bits), o Linux (64 bits)
- Cliente de Steam instalado
